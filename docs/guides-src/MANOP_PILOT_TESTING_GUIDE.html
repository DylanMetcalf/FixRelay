ManOp – Pilot testing guide

From reported to resolved.
For invited pilot testers. Please work through the tasks and note anything confusing.
Screenshots are taken from the running application with synthetic sample data. Version of 2026-11-25.

Before you start

  • Warm-up: open the live demo at /demo, take the tour, and try View as for two roles.
  • Use your work email. You need a phone with a camera and a computer.
  • The pilot uses test data only. Do not enter real personal information about other people.
  • If something is unclear, write down what you expected and what happened. Screenshots help.
